# Codealong logo concepts

Ten app-icon directions generated with the built-in image generation tool on September 24, 2026.

## Product understanding

Codealong is a native Mac companion for people running multiple coding agents. It gathers sessions across harnesses and accounts, organizes them by project, repository, worktree, branch and pull request, shows activity and human attention states, and opens the right session where it already lives. Account usage and a floating status bar keep this awareness close at hand.

The visual brief is calm awareness of parallel work: organized lanes, connected branches, a clear attention signal, and continuity between agent work and the human's next turn. The concepts use the existing charcoal (`#15181a`), ivory (`#e8ebe7`) and amber (`#f5a524`) palette.

Sources reviewed: the repository README, design tokens, current SVG and PNG app icon, main React view, floating bar implementation, and an existing sessions preview.
