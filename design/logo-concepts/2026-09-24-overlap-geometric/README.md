# Geometric Overlap explorations

Eight new constructions of the selected Codealong Overlap C, September 24, 2026.

The user asked for a more geometric version after the first ten Overlap variations. This batch keeps the turquoise, cobalt and dark-blue overlap palette while exploring circles, right angles and polygonal contours. These are raster concept images for comparing directions, not production vector artwork.
