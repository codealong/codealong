# Codealong — Overlap variations

Ten variations of candidate **22 Overlap**, numbered **91–100**. The user selected Overlap as their favorite and asked to explore it while retaining the simple, geometric, flat direction.

Generated individually with the built-in image_gen tool. Each generation uses the existing #22 PNG as an edit target. The prompts preserve the right-opening C, two broad curved pieces, and a single darker intersection. They request solid fills without gradients, depth, texture or shadows.
